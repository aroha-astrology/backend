# C. Critical corrections

Every item that needs a code change, with its state. Wording-only items are in the plan's Group 4 and are worked in release R4.

States: `FIXED` (failing test written first, now passing), `OPEN`, `NEEDS TEXT` (the old passage must be read and entered in `D-source-register.md` before any code changes), `NEEDS DECISION` (a product choice for the owner).

Nothing here is live. All fixes sit on branch `feat/engine-source-audit`. `CALCULATION_VERSION` and `RULESET_VERSION` are raised once when release R1 is approved, not per fix.
